# Horizon topic rules

## Required fields

For every topic, verify and record:

- Topic ID, using the compact suffix shown consistently by the site
- Exact official English title in verification
- Reviewed Korean title on the program page and in verification
- Action Type
- Maximum EU funding rate
- Topic budget in millions of euros

Do not infer a topic budget from the call total when the official source provides topic-level allocations.

## Funding-rate guide

Use the topic's official conditions when they override the defaults.

| Action Type | Displayed maximum rate |
| :--- | :--- |
| RIA | `100%` |
| IA | `영리 70% · 비영리 100%` |
| CSA | `100%` |
| PCP | `100%` |
| PPI | `50%` |
| COFUND | Explicit topic rate, commonly `30–70%` |

Spell out the action types immediately below the table when they appear. Keep the 25% indirect-cost calculation separate from the EU funding rate.

## Source placement

Place a direct source sentence immediately after the topic table:

```markdown
토픽의 공식 조건은 [Funding & Tenders Portal](CALL_URL), 상세 내용은 [Work Programme PDF](PDF_URL)에서 확인할 수 있습니다.
```

If the call has no separate thematic PDF:

```markdown
토픽의 공식 조건과 상세 내용은 [Funding & Tenders Portal](CALL_URL)에서 확인할 수 있습니다.
```

## Translation decisions

- Translate the concept, not merely the sound, when a clear Korean term exists.
- Preserve an unfamiliar official term in parentheses on first use: `식품 성분체(foodome)`.
- Preserve and explain acronyms when readers need them: `CBRN-E(화학·생물·방사능·핵·폭발물)`.
- Prefer established Korean technical terminology: `sodium-ion batteries` → `나트륨 이온 배터리`.
- Avoid translating `foodome` as `푸도믹스`; `foodomics` is the analytical field.
- Keep brands, project names, and consortium names in their official form unless an established Korean form exists.

## Eligibility review

Check both general and topic-specific conditions. Report:

- Whether Korean entities can participate and coordinate
- Country or associated-country restrictions
- Control/ownership restrictions, explained as such rather than nationality bans
- Required public authorities or practitioner beneficiaries
- Multi-actor approach requirements
- Geographic or policy mandates
- Mono-beneficiary or consortium-size rules
- Named predecessor-consortium restrictions

Write the practical conclusion before the legal explanation.
