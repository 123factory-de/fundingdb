# Funding DB

> 한국 기업이 지원할 수 있는 유럽·독일 R&D 지원사업(Horizon Europe, EUREKA·Eurostars와 클러스터, 한-독·한-스위스·한-프랑스·한-스페인 양자협력)을 한국어로 정리한 데이터베이스입니다. 123 Factory(https://www.123factory.de/)가 운영합니다.

- 모든 항목은 각 사업의 공식 공고·공식 웹사이트를 근거로 작성하며, 각 공고에 출처 링크와 최종 확인일(`verified`, YYYY-MM-DD)을 표기합니다. 공식 공고가 최종 기준입니다.
- 상태(`status`) 값: `open` 모집중, `planned` 공고 예정(접수 전), `closed` 마감.
- 날짜는 YYYY-MM-DD입니다. 마감 시각(예: 17:00 브뤼셀)은 각 공고 본문에 있습니다.
- 언어는 한국어이며 공고명·공고 번호(예: HORIZON-CL5-2026-11)는 원문 표기를 병기합니다.
- 등록 사업 {{ len $programs }}건 (모집중·공고 예정 {{ len $active }}건, 마감 {{ len $closed }}건), 생성 시각 {{ now.Format "2006-01-02" }}.
